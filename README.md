# Ai-Property-Rental-MERN-STACK-

AI Property Rental Manager is a full-stack MERN Stack web application that helps users find
and rent properties through an easy-to-use property rental platform. Users can browse
properties, search and filter properties based on their requirements, view property details,
and send rental requests to property owners. Property owners can add and manage their
properties and handle rental requests. The platform also includes AI-powered property
recommendations and description generation, secure authentication, role-based access,
dashboards, and rental management for users, owners, and administrators.
